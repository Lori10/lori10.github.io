Autonomous AI Research Agent with BabyAGI

Autonomous agent that answers research questions with factual, referenced answers by orchestrating three LLMs: a task-generation LLM breaks the objective into a task list, a task-execution LLM works through each task and stores enriched results in a vector database (Chroma or Weaviate), and a prioritization LLM re-ranks the remaining tasks based on progress so far. Extends the open-source BabyAGI with a final answer-generation LLM and fixes to its task generation. The execution step pulls papers from arXiv, ChemRxiv, and PubMed through their APIs and runs semantic search over them to ground GPT-3.5-turbo. Results come back as structured JSON with the answer and the source paper it relied on.

06

Autonomous AI Research Agent with ReAct

Research agent built on the ReAct pattern, which interleaves chain-of-thought reasoning with tool calls. It breaks a question into sub-questions and keeps questioning and answering itself until it can answer the original question with confidence. For each sub-question, a custom tool retrieves relevant papers from arXiv, ChemRxiv, PubMed, and other sources, then runs semantic search over them so GPT-3.5-turbo answers from the retrieved text rather than from memory. The final JSON output contains the answer and the reference paper it came from, so it plugs straight into downstream tools.

07

Text Classification with SETFIT

Research study on prompt-free few-shot text classification with SETFIT. It fine-tunes a pre-trained Sentence Transformer on sentence pairs in a contrastive Siamese setup, then trains a classification head on the resulting embeddings. Benchmarked on SST-2, SentEval-CR, and ADE-corpus-v2 over 5 random splits against standard BERT fine-tuning. With 18 training samples, SETFIT beat fine-tuned BERT by an average of 22.6 accuracy points and trained an order of magnitude faster. I also proposed a hard negative/positive sampling method for building the contrastive pairs, which beat SETFIT's default random sampling by 1.1 points on average at 50 samples. The code, data, and full write-up are public.

08

Loan Approval Prediction

Classifier that predicts whether a loan application will be approved from financial and loan-request features, trained on a highly imbalanced dataset of 100,000+ records. Handled the class imbalance with class weighting, an Easy Ensemble classifier, and up/downsampling. The resampling runs inside scikit-learn pipelines so that only the training folds are resampled during cross-validation, which prevents data leakage. Compared XGBoost, Random Forest, and Easy Ensemble tuned with RandomizedSearchCV on AUC, and selected features with recursive feature elimination. Built with object-oriented code and served through a Flask web app that supports retraining, with logging of each cleaning and training run.

09

Real Estate Price Prediction

Regression model that predicts Bengaluru house prices from 13,000+ very messy Kaggle listings. Most of the work was data cleaning: property sizes came in a mix of units and formats and were standardized to square feet, and high-cardinality locations were grouped into their top categories before one-hot encoding. Outliers were removed with business rules from a real-estate domain expert, such as a 300 sqft-per-bedroom minimum and price-per-sqft bands for each location. Compared Linear Regression, Random Forest, and KNN inside leak-free pipelines covering feature selection, scaling, and RandomizedSearchCV tuning. Random Forest scored best with a test R² of 0.88. Served through a Flask web app with retraining and training-history logging.

10

Traffic Sign Recognition with CNN

Computer-vision classifier for 43 types of traffic signs, the kind of recognition used in self-driving and driver-assistance systems. Preprocessing converted images to grayscale, normalized them, and shuffled them. Starting from a LeNet-style CNN, I tried several ways to reduce overfitting and improve generalization: early stopping, hyperparameter search with KerasTuner RandomSearch, data augmentation, and transfer learning from VGG16. Each model was compared on training, validation, and test accuracy and loss. The tuned LeNet gave the best balance, with about 94% test accuracy and a much lower test loss than the baseline. Served through a Flask web app.

11

Grammar Checker and Corrector

Two-stage grammar tool. The first stage is a bigram language model written from scratch: it counts n-grams, adds sentence start and end markers, applies add-k smoothing, and scores how probable each sentence is, flagging it as incorrect if the score falls below a threshold. The k-smoothing value and the threshold were tuned together to maximize F1 on incorrect sentences, raising AUC from 0.67 to 0.83 and recall to 1.0. The second stage uses a fine-tuned T5 Transformer to classify sentences and rewrite the incorrect ones. Served through a Flask web app.
